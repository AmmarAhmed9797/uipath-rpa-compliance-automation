## 📌 About This Project

Built at **360factors** to automate compliance reporting workflows in the **Predict360 GRC platform**. Reduced manual effort for compliance officers by automating repetitive, rule-based tasks using UiPath Studio.

### Key Achievements
- ✅ Automated compliance report generation saving hours of manual work per week
- ✅ Scheduled regulatory submission workflows with zero human intervention
- ✅ Exception handling with automated alerts and escalation workflows
- ✅ Integrated with Predict360 APIs for data extraction and report population

## 🚀 Automated Workflows

- **Compliance Report Generator** — Auto-generates monthly/quarterly reports
- **Regulatory Submission Bot** — Submits filings to regulatory portals
- **Policy Expiry Notifier** — Alerts stakeholders of expiring policies
- **Audit Data Extractor** — Pulls audit logs and formats for review
- **Third-Party Risk Alerts** — Monitors vendor risk scores and triggers alerts
